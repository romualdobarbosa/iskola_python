# Dica do 012 · Grãos no tabuleiro

A casa n tem o 2 multiplicado por ele mesmo n - 1 vezes, e o Python tem um operador de potência. O total dá pra somar num laço, mas escreva os primeiros totais num papel (1, 3, 7, 15) e compare com as potências de 2. Quanto ao tamanho dos números, o int do Python cresce o quanto precisar.

## Termos que valem uma pesquisa

- o operador de potência em Python
- inteiros de precisão arbitrária
- soma de uma progressão geométrica
