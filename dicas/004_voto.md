# Dica do 004 · Voto

Tudo que o input devolve é texto, mesmo quando a pessoa digita um número. Pra comparar com 16, a idade precisa virar inteiro antes. Depois disso, a ordem das condições importa, e as faixas do enunciado se resolvem com uma cadeia de condições e, se quiser, um operador lógico juntando as duas faixas de facultativo.

## Termos que valem uma pesquisa

- a função int
- if, elif e else em Python
- operadores lógicos and e or
