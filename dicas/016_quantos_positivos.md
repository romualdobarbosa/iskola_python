# Dica do 016 · Quantos positivos

Uma comparação devolve True ou False, e no Python o bool é um tipo de inteiro, então dá pra somar comparações. Pra faixa, o Python deixa encadear comparações como se escreve na matemática, sem repetir a variável com and.

## Termos que valem uma pesquisa

- o tipo bool como subclasse de int
- comparações encadeadas em Python
