# Dica do 007 · Média de duas notas

O int() só aceita texto que pareça um inteiro, então "7.5" quebra. Existe uma função irmã pra número com casa decimal. Na divisão, o Python tem dois operadores diferentes, e um deles sempre devolve número com vírgula, mesmo quando a conta dá exata. Pra controlar quantas casas aparecem, a f-string aceita uma especificação de formato depois do nome da variável.

## Termos que valem uma pesquisa

- a função float
- divisão verdadeira e divisão inteira em Python
- especificação de formato na f-string
