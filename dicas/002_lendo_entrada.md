# Dica do 002 · Lendo a entrada

Se só o primeiro caso passou, provavelmente o nome do exemplo ficou escrito direto no código. Cada caso manda um nome diferente, então o programa tem que ler o nome e montar a frase com ele.

## Termos que valem uma pesquisa

- a função input
- concatenação de strings
- f-string
