# Solução do 001 · Olá, mundo

```python
print("Olá, mundo!")
```

O template imprimia "ola mundo" e o enunciado pedia "Olá, mundo!". Faltavam a maiúscula, o acento, a vírgula e a exclamação. O corretor não aceita "quase igual", e é bom acostumar com isso logo no primeiro problema, porque nos próximos a diferença vai estar num espaço ou numa linha a mais.

O acento funciona sem nenhuma configuração. No Python 3 toda string é Unicode e o arquivo é lido como UTF-8.

## Complexidade

Tempo O(1) e espaço O(1). Uma linha, sempre a mesma.
