# 0001. Problemas originais, licença MIT

Status: aceito (2026-10-23)

## Contexto

O formato dos drills vem do URI (começo) e do LeetCode (fim). Copiar enunciados ou números de lá traria problema de direito autoral e deixaria o projeto dependente de outro site.

## Decisão

Os 100 problemas são originais. O URI só inspira, sem citação nem cópia de texto ou número. O código e o conteúdo saem sob licença MIT, no nome de Romualdo Barbosa. Primeiro em PT-BR; a versão EN vem depois, pra comunidade.

## Consequências

Cada enunciado, caso de teste e gabarito precisa ser escrito do zero. A tradução fica mais fácil porque todo texto de interface mora em `iskola/mensagens.py` (ver 0007).
